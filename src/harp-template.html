What this is

Nothing here is a recording. Each glass is a full physics model running on its own: an elastic crystal shell solved from its shape, water flowing inside it, and a wet fingertip that grips and slips around the rim. That stick–slip finds each glass's note by itself.

Tuning works the way a glass-harp maker does it. The auto-tuner picks each glass's size, then pours water until the model sings exactly on the note. The keys pour water too. Water only lowers a glass's pitch, so each glass covers about 9–11 semitones.

Each glass is the same physics as the solo page (shell FE, potential-flow water, stick–slip finger), running as an independent voice. A glass's pitch range is set by its size: water can only lower it, by about 9–11 semitones from empty to nearly full.
